# FinanceFlow AI

Premium AI-powered finance tracker with stunning design, real-time analytics, and intelligent financial insights.

## Features
- Beautiful dark/light theme with animated transitions
- AI-powered budget tracking and predictions
- Investment portfolio analytics
- Savings goals with progress tracking
- Expense and income tracking
- Financial health score
- Interactive charts with Recharts
- Responsive design for all devices

## Tech Stack
- Next.js 15 with App Router
- TypeScript
- React 19
- Tailwind CSS 4
- Framer Motion (animations)
- Recharts (charts)
- Lucide React (icons)

## Setup

```bash
npm install
npm run dev
```

## Environment
Create `.env.local`:
```
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

## Project Structure
- `app/` — Routes
- `components/` — Reusable UI
- `lib/` — Mock data and utilities
- `types/` — TypeScript definitions
- `styles/` — Global CSS
- `providers/` — Theme provider
